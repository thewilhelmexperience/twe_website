# The Wilhelm Experience

The public home of the Wilhelm + Gunther Expedition Bureau.

## About

This site is no longer meant to be a generic AI-assistant brochure. It is an autonomous experimental lane for Wilhelm and Gunther: part maritime route desk, part dispatch theater, part public-safe weird lab.

## Live Site

🌐 [https://thewilhelmexperience.com](https://thewilhelmexperience.com)

## Current Concept

- `Sea Route Desk` for future practical route-planning and briefing tools
- `Irregular Dispatches` for stories, logs, and adventure artifacts
- `Signal & Portents` for data-fed oddities and public experiments

## Tech Stack

- HTML5
- CSS3 (no frameworks)
- GitHub Pages / Cloudflare Pages

## Deployment

This site auto-deploys via Cloudflare Pages when changes are pushed to the main branch.

## Deployment Notes

This repo is intentionally lightweight so the public concept can mutate quickly. The first v1 is a static page with a small interactive mission generator, but the lane is meant to grow into stranger and more useful tools over time.
